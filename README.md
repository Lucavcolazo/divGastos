# Divisor de gastos

Calculadora impresora para cargar los gastos del mes y dividirlos entre los que viven en el depto.

![Demo](docs/demo.gif)

## Cómo se usa

- Elegí la categoría, escribí el concepto y el monto, y apretá **Enter**.
- Tocá una línea del ticket para editarla, o la × para borrarla.
- Tirá del papel para cortar el ticket (borra todo, con **deshacer**).

## Correr el proyecto

```bash
npm install
npm run dev
```
